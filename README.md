# VishnupriyaRayaprolu.github.io
Vishnupriya UX Research portfolio

## Build (Tailwind CSS)

This site uses Tailwind v4 + tw-animate-css. To build the CSS:

```bash
npm install
npm run build
```

This compiles `styles/input.css` → `styles/main.css`. Run `npm run build` after changing theme or styles.
